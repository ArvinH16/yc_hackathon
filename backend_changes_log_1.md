### 5. [backend/prompt_generator.py](backend/prompt_generator.py)

**Purpose:** AI-powered system prompt generator using Gemini 2.0 Flash.

**Key Features:**
- `load_business_info()` - Loads business data from JSON file
- `generate_prompt_with_gemini()` - Uses Gemini AI to create custom conversation prompts
- `_get_fallback_prompt()` - Provides basic template if Gemini fails
- `get_custom_prompt()` - Main entry point for prompt generation

**How It Works:**
1. Loads business information from JSON
2. Creates a meta-prompt asking Gemini to generate a conversation prompt
3. Gemini analyzes business details and creates context-aware instructions
4. Returns a detailed system prompt for the AI caller

**Prompt Requirements:**
- Act as potential customer interested in services
- Gather intelligence: pricing, services, availability, team, AI adoption
- Detect if receptionist is AI or human
- Maintain natural, conversational tone
- Keep responses concise for voice output

**Impact:** Transforms static prompts into dynamic, intelligent conversation flows tailored to each business.

---

### 6. [backend/make_call.py](backend/make_call.py)

**Purpose:** CLI tool for easily initiating outbound calls using business info.

**Usage:**
```bash
uv run make_call.py [--local]
```

**Features:**
- Loads business info from `business_info.json` automatically
- Reads server URL from `.env` or uses localhost
- Makes POST request to `/start` endpoint
- Provides detailed logging and error handling
- Shows call status and SID on success

**Options:**
- `--local` / `-l` - Force use of localhost instead of ngrok URL

**Impact:** Simplifies call initiation workflow - no need to manually construct curl commands or remember phone numbers.
